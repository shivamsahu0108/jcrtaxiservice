# Jabalpur Car Rental Taxi Service

A responsive React + Vite + Tailwind CSS premium sample website for a local taxi/car rental business in Jabalpur.

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Before publishing

Edit `src/main.jsx`:

- BUSINESS.name
- BUSINESS.phone
- BUSINESS.whatsapp
- BUSINESS.email
- BUSINESS.address
- BUSINESS.url
- vehicle prices
- service details
- routes
- package details

Edit `index.html`:

- canonical URL
- meta description
- Open Graph URL/image
- title

Edit `public/sitemap.xml` and `public/robots.txt` to use the real domain.

## SEO notes

The starter includes:

- Local TaxiService JSON-LD
- title and meta description
- canonical URL
- Open Graph metadata
- robots.txt
- sitemap.xml
- semantic H1/H2/H3 structure
- service and route content
- mobile-first responsive design
- internal anchor navigation
- WhatsApp booking links

For a real production site, create separate crawlable route/service pages rather than relying only on anchor sections.
