# Jabalpur Car Rental Taxi Service

Production-oriented React, Vite and TypeScript website for Jabalpur Car Rental Taxi Service.

## Local development

```bash
npm install
npm run dev
npm run build
```

Business details are centrally maintained in `src/config/business.ts`. Content collections are in `src/data/` and WhatsApp enquiry formatting is in `src/utils/whatsapp.ts`.

## Image assets

Place licensed, accurately labelled WebP photography in the matching folders under `public/images/`. Landmark images must be real, relevant photographs and vehicle imagery must not imply unverified fleet ownership.
